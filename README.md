# Lublin-TrolleyNetFix

## English

### Overview

It is well known that several areas of the Lublin map contain overhead-wire networks that openOMSI cannot natively read. This add-on consolidates all overhead-wire definitions across the map, corrects excessive bend angles and adapts them for 18-metre vehicles, and adjusts the positions of the frogs generated by openOMSI, so that trolleybuses can raise their poles and connect to the wire anywhere on the map. Based on the original map network and with reference to Google Street View, additional stabling wires have been added near the depot entrance and the 158 terminus to better match reality; the wiring inside the depot has not yet been modified.

Known characteristic: when a merge point and a frog are too close together (less than 9 m), the native openOMSI frog-detection window occurs at the moment the merge is completed. If the vehicle passes the merge point too quickly, the pole loses contact for too long and the branch selection fails. At roundabouts, it is recommended to limit speed to 20 km/h or less when passing frogs.

### Requirements

- OMSI 2 **2.3.004 or newer**. Lublin 3.1 is tested on 2.3.004; OMSI 2.2.x is not supported. The 4 GB patch is strongly recommended.
- **openOMSI 0.3.52 or newer**.
- Lublin `Projekt_Lublin_2017` 3.1 with 273 `tile_*.map` files.
- The seven O3D files in `Sceneryobjects\Lublin\Kostki sterujace ruchem AI\model`:
  `Rondo_Krupskiego.o3d`, `UniiXZamojska.o3d`, `RondoLubelskiegoLipca3.o3d`,
  `DMMXWolska.o3d`, `GrygowejXPancerniakow.o3d`, `zamojska.o3d`, `zamojska2.o3d`.

The installer refuses a map that has already been modified and has no clean backup.

### Installation (bat)

1. Double-click `install.bat`.
2. The script auto-detects OMSI 2 from Steam, the Windows registry, the location of this package and the common drive layouts. Press Enter to accept the detected folder, or enter another path.
3. Alternatively, drag the OMSI 2 folder onto `install.bat`.

If OMSI is installed under `Program Files`, right-click `install.bat` and choose **Run as administrator**.

To roll back, double-click `revert.bat` and enter the same OMSI folder.

### Installation (PowerShell)

```powershell
# Auto-detect the OMSI folder
powershell -ExecutionPolicy Bypass -File tools\install.ps1

# Specify the OMSI folder explicitly
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -OmsiRoot "E:\SteamLibrary\steamapps\common\OMSI 2"

# Keep .map.prt and tile_*.rdy
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -OmsiRoot "<OMSI>" -KeepCaches

# Roll back
powershell -ExecutionPolicy Bypass -File tools\install.ps1 -OmsiRoot "<OMSI>" -Revert
```

## 中文

### 简介

众所周知，卢布林地图中有多个区域的接触网无法被 openOMSI 原生解析。本 Addon 对全图接触网定义进行了整合，修正了过大的折角并适配 18 米车辆，同时调整了 openOMSI 自动生成分线器的位置，从而使全图无轨电车均可正常升杆并接入线网。在原地图线网的基础上，参照 Google 街景，于停车场入口及 158 路终点站附近增补了停车线，使线网更贴近现实；停车场内部线网目前尚未修改。

已知特性：当并线器与分线器距离过近（小于 9 米）时，openOMSI 原生分线器的识别窗口位于并线器完成并入的瞬间；若车辆通过并线器的速度过快，将导致集电杆断触时间过长并使分线失败。因此，环岛处的分线器建议将车速限制在 20 km/h 以下。

### 环境要求

- OMSI 2 **2.3.004 或更新版本**。Lublin 3.1 在 2.3.004 上测试；不支持 OMSI 2.2.x。强烈建议安装 4 GB patch。
- **openOMSI 0.3.52 或更新版本**。
- Lublin `Projekt_Lublin_2017` 3.1，包含 273 个 `tile_*.map`。
- `Sceneryobjects\Lublin\Kostki sterujace ruchem AI\model` 目录下的 7 个 O3D 文件：
  `Rondo_Krupskiego.o3d`、`UniiXZamojska.o3d`、`RondoLubelskiegoLipca3.o3d`、
  `DMMXWolska.o3d`、`GrygowejXPancerniakow.o3d`、`zamojska.o3d`、`zamojska2.o3d`。

对于已经修改且没有干净备份的地图，安装器将拒绝执行。

### 安装（bat）

1. 双击 `install.bat`。
2. 脚本会从 Steam、Windows 注册表、本安装包所在位置以及各磁盘的常见目录自动查找 OMSI 2。按回车确认检测到的目录，或输入其他路径。
3. 也可以将 OMSI 2 文件夹直接拖到 `install.bat` 上。

如果 OMSI 安装在 `Program Files` 目录下，请右键单击 `install.bat`，选择 **以管理员身份运行**。

如需回退，双击 `revert.bat` 并输入相同的 OMSI 目录。
